# Security Policy

## Supported Versions

Only the latest version of WToDo is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within WToDo, please do **not** open a public issue. Instead, please report it via the following process:

1. Open a private security advisory on the repository (GitHub → Security → Report a vulnerability).
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce the issue (PoC).

### Our Commitment

- We will acknowledge receipt of your report within 48 hours.
- We will provide an estimated timeline for a fix.
- We will notify you once the vulnerability is patched.
- We will give you credit for the discovery in our release notes (unless you prefer to remain anonymous).

Please allow us reasonable time to fix the issue before disclosure. We believe in responsible disclosure and will work with you to ensure the safety of our users.
